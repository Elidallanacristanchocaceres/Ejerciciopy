📂 Repositorio de Proyectos en Python 🐍
¡Bienvenido a este repositorio! Aquí encontrarás una colección de proyectos en Python que abarcan desde gestión de torneos hasta análisis de datos y simulaciones de sismos. A continuación, te explico cada uno de ellos con detalles y emojis para que puedas entenderlos mejor. 😊

🏓 1. Sistema de Gestión de Torneo de Tenis de Mesa
📝 Descripción
Este proyecto permite gestionar un torneo de tenis de mesa, donde los jugadores se registran en diferentes categorías (Novato, Intermedio, Avanzado) según su edad. Además, se pueden registrar partidos, mostrar estadísticas y determinar al ganador de cada categoría.

🛠️ Funcionalidades
Registro de jugadores 👤

Inicio del torneo 🏁

Registro de partidos 🎯

Estadísticas de jugadores 📊

Determinar ganadores por categoría 🏆

🖥️ Cómo Usar
Ejecuta el archivo main.py.

Sigue las instrucciones del menú para registrar jugadores, iniciar el torneo y registrar partidos.

Consulta las estadísticas y los ganadores.

🌍 2. Sistema de Gestión de Dependencias y Consumo de Energía
📝 Descripción
Este proyecto simula la gestión de dependencias (edificios, oficinas, etc.) y su consumo de energía. Permite registrar dispositivos eléctricos, calcular el consumo en kWh y estimar las emisiones de CO₂.

🛠️ Funcionalidades
Registro de dependencias 🏢

Registro de dispositivos eléctricos 💡

Cálculo de consumo de energía ⚡

Estimación de emisiones de CO₂ 🌫️

Identificación de la dependencia con mayor emisión 🚨

🖥️ Cómo Usar
Ejecuta el archivo main.py.

Registra dependencias y dispositivos eléctricos.

Consulta el consumo de energía y las emisiones de CO₂.

🏪 3. Sistema de Gestión de Inventarios
📝 Descripción
Este proyecto permite gestionar el inventario de productos en una tienda. Incluye funcionalidades para registrar productos, actualizar el stock, identificar productos críticos (con stock bajo) y calcular la ganancia potencial.

🛠️ Funcionalidades
Registro de productos 📦

Actualización de stock 🔄

Identificación de productos críticos ⚠️

Cálculo de ganancia potencial 💰

🖥️ Cómo Usar
Ejecuta el archivo main.py.

Registra productos y actualiza su stock.

Consulta los productos críticos y la ganancia potencial.

🌋 4. Simulador de Sismos y Análisis de Riesgo
📝 Descripción
Este proyecto simula la gestión de sismos en diferentes ciudades. Permite registrar ciudades, agregar sismos y generar un informe de riesgo basado en la magnitud promedio de los sismos.

🛠️ Funcionalidades
Registro de ciudades 🏙️

Registro de sismos 🌍

Búsqueda de sismos por ciudad 🔍

Informe de riesgo 🚨

🖥️ Cómo Usar
Ejecuta el archivo main.py.

Registra ciudades y sismos.

Consulta el informe de riesgo.

🧮 5. Calculadora de IMC y Análisis de Peso
📝 Descripción
Este proyecto calcula el Índice de Masa Corporal (IMC) de una persona y determina su estado de peso (normal, sobrepeso, obesidad, etc.). También permite analizar el IMC de un grupo de personas.

🛠️ Funcionalidades
Cálculo de IMC individual 🧍

Análisis de IMC grupal 👥

Clasificación de peso ⚖️

🖥️ Cómo Usar
Ejecuta el archivo main.py.

Ingresa los datos de las personas.

Consulta el análisis de IMC.

🔢 6. Análisis de Números Enteros
📝 Descripción
Este proyecto permite ingresar números enteros positivos y realiza un análisis estadístico, incluyendo el conteo de números pares e impares, promedios, y rangos específicos.

🛠️ Funcionalidades

Cálculo de promedios 📊

Análisis de rangos 🎯

🖥️ Cómo Usar
Ejecuta el archivo main.py.

Ingresa números enteros positivos.

Consulta el reporte estadístico.
